# 现代网文与强追读叙事

## 目录

1. 阅读动力
2. 人物与冲突
3. 节奏设计
4. 信息控制
5. 常见失效模式

## 1. 阅读动力

同时维持三层动力：

- 即时问题：本场景能否解决眼前危机？
- 阶段问题：主角能否完成当前目标或跨越当前门槛？
- 长线问题：身份、关系、世界真相或终极代价是什么？

短篇也应有至少前两层。段尾钩子不必总是危机，可以是新信息、新决定、新代价或期待中的会面。

## 2. 人物与冲突

快速建立人物时，给出一个可见困境、一个具体习惯和一个自相矛盾之处。主角可以强，但不能没有盲点；优势最好制造新的麻烦。

对手不只是“坏”，而是代表一种与主角冲突但可自洽的生存答案。配角至少承担以下一种功能：施压、诱惑、见证、映照、提供错误答案。合并功能重复的配角。

## 3. 节奏设计

每个段落或场景完成至少一项：兑现旧期待，建立新期待，改变力量关系，增加代价，重释已知信息。

采用“承诺—推进—部分兑现—更大代价”的循环。持续拖延兑现会消耗信任；过早完全兑现会让故事失去引擎。

动作、对话、内心和信息说明要交替使用。高压场景缩短句段并减少解释；情绪余波适度放慢，让代价落地。

中篇每一阶段都应有一个局部不可逆点，例如公开决裂、失去退路、错误胜利、交换秘密或承担债务。

## 4. 信息控制

一次只解释当前行动必需的设定。优先通过人物为了目标使用规则、触犯规则或为规则付费来展示世界。

区分三种悬念：

- 好奇：究竟发生了什么？
- 担忧：已经知道危险，会不会来得及？
- 期待：已经知道能力或计划，何时以及如何兑现？

不要全篇只靠谜团。交替使用三种悬念，才能避免故弄玄虚。

## 5. 常见失效模式

- 开场全是背景：把第一条设定放进冲突现场。
- 主角被动接任务：让其主动选择一个有私人理由的目标。
- 升级只是敌人更强：同步提高关系、身份或道德代价。
- 反派为推动剧情变蠢：让主角靠付出、判断或利用已知规则赢。
- 连续打脸没有变化：每次胜利必须改变处境并产生新账单。
- 金手指无代价：增加限制、暴露风险、误用后果或价值冲突。
- 结尾突然升华：让主题通过此前反复出现的选择自然完成。
- 为续作不收尾：先完成本篇核心情绪闭环，再留下更大的世界问题。
